# 🔍 Analysis

This folder contains all forensic analysis outputs for the AWS Cloud Breach DFIR case study.

## Contents
- **timeline.md** — chronological reconstruction of attacker activity  
- **ioc-list.md** (optional) — indicators of compromise  
- **queries.md** (optional) — CloudTrail Lake, Athena, and Sigma hunting queries  
- **screenshots/** — visual evidence collected during analysis  

The analysis in this folder supports the final incident report and MITRE ATT&CK mapping.
