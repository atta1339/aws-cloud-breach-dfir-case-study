# 🗂 Evidence Collection

This folder contains all forensic evidence gathered during the AWS Cloud Breach DFIR investigation.

## Structure
- **cloudtrail/** — CloudTrail event logs used for timeline reconstruction  
- **guardduty/** — GuardDuty findings related to reconnaissance and privilege escalation  
- **vpc-flow-logs/** — Network flow logs showing data movement and exfiltration patterns  
- **screenshots/** — Visual evidence captured during analysis  

Evidence in this folder supports the final incident report and MITRE ATT&CK mapping.
